# DSH Market Pro Logo

正式资源为手工构建的 `assets/logo.svg`，不含位图、渐变、滤镜、字体或外部引用。`assets/logo.png` 是从同一 SVG 栅格化的 256 × 256 透明 PNG，便于不支持 SVG 的使用场景。

## 图形与颜色

保留盾牌、2 × 2 插件模块与对勾的构图。四格统一为 56 × 56、圆角半径 12 的方块，水平和垂直间距均为 12。移除遮阳棚下摆和对角配色，前三格使用相同浅色，仅右下格使用强调蓝及白色对勾。网格下移，保留盾牌尖角的留白；对勾采用 8 单位粗线，在 32px 图标中对应 1px。

| 用途 | 色值 |
| --- | --- |
| 盾牌底色 | `#061A4D` |
| 普通模块 | `#E8EEF8` |
| 审查模块 / 强调色 | `#2864DC` |
| 对勾 | `#FFFFFF` |

此处固定深蓝底、单一强调蓝及模块圆角比例（12/56），作为本插件后续图形的规范；其他插件 Logo 的统一需以其正式矢量源稿为依据。

## 对比度验证

按 sRGB 线性化后的相对亮度计算 `(L亮 + 0.05) / (L暗 + 0.05)`，使用 SVG 中的实际色值：

| 相邻图形 | 对比度 |
| --- | --- |
| 白色对勾 / 蓝色模块 | **5.32:1** |
| 浅色模块 / 深蓝盾牌 | **14.27:1** |
| 蓝色模块 / 深蓝盾牌 | **3.13:1** |

这些数值描述纯色区域的对比度；小尺寸抗锯齿边缘仍通过实际栅格化预览检查。
